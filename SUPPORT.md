# Support

Use the repository issue tracker for bugs, regressions, and feature requests.

When reporting a problem, include:

- VS Code version
- Slab extension version
- Operating system
- Whether the problem happens in a markdown file, notebook markdown cell, or notebook export
- A minimal markdown or notebook snippet if the issue involves LaTeX, preview rendering, scaffold parsing, or export output

Do not include private notebooks, credentials, API tokens, or unpublished course material unless you have already reduced the example to non-sensitive content.
